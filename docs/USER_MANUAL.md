## 1. 怎么进入

在电脑或手机浏览器里打开：

**https://todo.tangent0712.top**

（手机也可以直接用，会自动适配成手机版样式。）

---

## 2. 登录

- 输入**自己的 API Key**（找管理员要，一串像 `tt_xxxxxxxx` 的字符），点「登录」。
- 一个 Key 就是一个独立的账号，每个人看到的课表、待办都是自己的，互不影响。
- 登录后右上角会显示你的名字。

> 忘了 Key？找管理员重新要一个就行，不影响已有数据。

---

## 3. 第一次进来先做什么

登录后进入「课表」页，如果还没有课表，按提示点「新建课表」：

- **课表名称**：随便起，比如「大三上学期」。
- **开始日期 / 结束日期**：填这学期第一周周一的日期，和最后一周周日的日期（或学期最后一天）。
- 一个账号可以建**多个课表**（比如按学期分开），左侧可以切换当前用哪个。

> 建好课表后，就可以往里面加课程了。

---

## 4. 课表页面（看课表）

- 默认显示**按周**的视图，可以看到一周 7 天、每天 12 节课的格子。
- 顶部可以**翻页看第几周**，点「本周」直接回到当前周。
- 点右上角「全部课程」，可以按列表方式看所有课程。
- 格子颜色 = 课程颜色，同一门课颜色固定，方便找。
- 屏幕不够宽时，课表会自己变紧凑；手机上可以左右滑动看完整网格。

### 一个格子里的信息

- **课程名**、上课地点、老师。
- 点一下格子可以**修改或删除**这门课。

## 5. 课程管理（添加/修改/删除课程）

**添加课程**：点「添加课程」按钮，填：

- 课程名称（必填）
- 上课地点、老师（选填，留空也行）
- 星期几、第几节到第几节
- 上课周次（哪几周有课）

**周次怎么填**：
- 在「上课周次」勾选具体周，或用下面的快捷输入：
  - `1-16` 表示第 1 到 16 周都有课
  - `1,3,5` 表示单周
  - 有「单周」「双周」「仅本周」「全选」按钮可以快速选。
- 点「应用」按钮把输入的周次应用上去。

**修改课程**：在课表里点课程格子 → 改完点「保存」。

**删除课程**：点课程格子 → 点「删除」。

**批量导入**：如果有教务系统的 HTML 课表，点「导入课表」→ 粘贴内容 → AI 自动识别 → 勾选要导入的 → 导入。方便一次性建课。

## 6. 考试记录（期末周用）

考试**不按课时算**，直接填日期和起止时间，适合期末周/四六级/普通话这类考试。

**添加考试**：课表页点「考试管理」→「添加考试」：

- 考试名称（比如「数据结构期末考试」「CET-6」）
- 考试日期
- 开始时间、结束时间
- 考试地点（选填）

**考试在课表上的显示**：
- 考试会**按它的日期和时间**，在课表对应位置显示一个**红色块**。
- 红块上显示：考试名称、开始/结束时间（两行）、地点。

**自动提醒**：
- 每加一场考试，系统会自动生成一条**待办**（截止时间 = 考试开始时间），并在待办列表里标成红色「考试」。
- 考试**结束后**，这条待办会自动标记完成，不用你手动删。

## 7. 待办事项（提醒自己）

在「待办」页面管理要交的作业、要办的事：

- **新建待办**：写标题 + 选截止时间，点保存。
- **标记完成**：勾选左边的方框。
- **修改 / 删除**：右侧的铅笔 / 垃圾桶图标。
- 顶部有统计：待完成、24 小时内到期、已逾期。
- 每条待办会显示**倒计时**（比如「2天3小时」），快到期会变色提醒。
- 「循环任务」标签页可以建**每周/每月重复**的提醒（进阶功能，见下方）。

### 循环任务（可选进阶）

如果有些事每周都重复（比如每周五交作业），可以：
- 在「待办」→「循环任务」→「新建循环任务」。
- 选频率（每天/每周/每月）、触发时间、截止时间（触发后多久截止）。
- 到时间系统会自动生成一条真实待办。
- 高级用户还能写自定义脚本（如「双周周五」），不会就不碰。

## 8. AI 助手（用一句话办事）

这是最有意思的功能：**不用手动点，用一句话让 AI 帮你干活。**

进入「AI 助手」页，在输入框里用大白话描述需求，比如：

- 「下周一3-4节加一节形势政策，地点待定」
- 「把周三的高数从第3-4节改到第5-6节」
- 「删掉周五上午的课，再加一条周三交实验报告的待办」
- 「下周五下午5点前交高数作业」
- 「12月16号加一场数据结构期末考试，下午2点到4点」

**怎么用**：
1. 输入你想做的事，按「发送」（Enter 发送，Shift+Enter 换行）。
2. AI 会回复文字，并在下面给出它准备执行的**操作卡片**。
3. **每条操作都要你点「确认执行」**才会真正改动；不想执行的点「取消」。
   - 一次说多件事，会生成多张卡片，**逐条确认**，不会偷偷帮你全做了。
4. 执行完可以继续聊、继续调整。

> 每次对话都绑定一个课表（工作空间）。如果切到别的课表，输入和操作会被锁定，
> 提示你切换回对应课表或新建对话，防止改错地方。

## 9. 设置（作息时间表 / 字体大小）

### 作息时间表

- 是**全校统一的上下课时间**（第几节几点到几点），课表格子就是按它排的。
- **仅供阅读，不可编辑**（管理员才能改）。改作息会影响课表显示和 AI 解析，所以不开放给大家。

### 字体大小

- 可以分别调「**全局其它字体**」和「**课程表字体**」的大小。
- 拖动滑块即可，**只保存在你这台设备上**，换设备需重新调。
- 「重置」可恢复默认。

## 10. 常见问题

**Q：登录不进去 / 提示 Key 无效？**
重新找管理员要一个有效 Key。

**Q：课表格子为什么有的课没显示？**
同一时间段撞了两门课，系统只会显示其中一门，并在格子上显示一个警告角标，点开能看到被顶掉的那门。去把时间调整开就好。

**Q：周次怎么填不对？**
先在「上课周次」下面用 `1-16` 这类格式输入，点「应用」；或直接勾选。带 `*` 的是当前周。

**Q：考试怎么没在课表上？**
考试是**按日期**显示的，要翻到它所在的那一周才能看到（翻页或点「本周」）。如果日期不在学期范围内也可能看不到。

**Q：AI 说的话我不太放心，会乱改吗？**
不会。AI 只会生成「提案卡片」，**必须你每条点「确认执行」**才会真正改动，不点就什么都不变。

**Q：我在手机上能用吗？**
能。所有页面都做了手机适配，窄屏会自动调整布局。

**Q：数据安全吗？**
每个账号数据互相独立，用自己 Key 登录只能看到自己的东西。
